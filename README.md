# FandyMusic

FandyMusic — клиентское веб-приложение музыкального плеера, построенное вокруг Spotify API.  
Проект создан как демонстрация архитектуры frontend-приложения с асинхронной бизнес-логикой, глобальным состоянием и авторизацией через сторонний сервис.

Проект: https://fandymusic.vercel.app

---

## Цель проекта

- Спроектировать SPA с авторизацией через внешний API
- Реализовать работу с асинхронными потоками данных (загрузка, ошибки, кеширование)
- Продемонстрировать управление глобальным состоянием и разделение ответственности
- Отработать архитектурный подход, близкий к продуктовому frontend-приложению

---

## Стек технологий

- **TypeScript** — строгая типизация и контроль контрактов
- **React** — компонентная архитектура
- **Redux Toolkit + RTK Query** — глобальное состояние, асинхронные запросы, кеширование
- **CSS Modules** — изолированная стилизация компонентов

---

## Реализованный функционал

- Авторизация пользователя через Spotify API
- Загрузка и воспроизведение треков
- Работа с плейлистами и лайками пользователя
- Глобальный поиск по трекам и исполнителям
- Получение рекомендаций на основе данных пользователя
- Обработка состояний загрузки и ошибок API

---

## Архитектурные решения

- Глобальное состояние вынесено в Redux Toolkit для управления пользовательскими данными и плеером
- Асинхронные запросы реализованы через RTK Query с кешированием и автоматической синхронизацией
- UI-компоненты отделены от бизнес-логики
- Логика работы с API изолирована от компонентов

---

## Ограничения проекта

- Приложение находится в активной разработке
- На текущий момент доступ возможен только через Spotify-аккаунт
- Для авторизации может потребоваться VPN (ограничения Spotify API)
